# Project Jason Architecture

This directory contains the authoritative engineering architecture for Project Jason.

## Structure

### `adr/`

Architecture Decision Records explaining significant technical decisions and their consequences.

### `jis/`

Jason Integration SDK engineering principles, provider-development procedures, templates, checklists, and milestone-closeout requirements.

### `providers/`

Provider-specific reference specifications, limitations, and validation status.

### `diagrams/`

Approved architecture diagrams. This directory may remain empty until diagrams are created during a future documented milestone.

## Authority

The Jason Constitution governs Project Jason as a whole.

This architecture directory governs implementation structure beneath the Constitution.

Provider-specific documentation must not override constitutional or JIS governance requirements.
