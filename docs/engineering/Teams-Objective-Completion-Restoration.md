## Independent Root boundary

Stage the exact canonical plan before presenting a card. Root retains its nonce,
original material and policy. Root renders and sends that exact reviewed
objective through the existing bot and records the actual provider message ID.
It accepts neither a caller's presentation nor a caller-asserted delivery.
The signed SDK callback must bind the same original message, nonce and plan.

Before each native step Root independently checks the current licensed Owner
binding, registered service, six exact current grants, source/CI, two ordered
actions, immutable artifacts, policy, protected peers, freeze, promotion hold,
Engineering Owner Pause, shared Root worker and accepted Stage E code.
An unknown effect requires independent native readback. A consumed claim is
never reset or blindly rerun. The original decision and all subordinate native
receipts remain auditable after process restart.

The source repository stays read-only inside the Root service. Protected main
and required checks come from the existing pinned verifier. Every newer commit
and its complete touched-path set are inspected through read-only GitHub API
evidence, including paths subsequently reverted. Only the two declared
mechanically generated documentation outputs may change as this objective's
own effect. Truncated, unavailable or overlapping evidence denies.

## Live acceptance

First send a separate nonexecuting Deny test. Mistaken Approve on that test has
no production effect and cannot unlock the real card. Then one real Approve
must cover both reviewed documentation steps and produce verified native
completion without another vote. Verify actual desktop/mobile rendering,
provider ID and SDK reply linkage, canonical decision, independent per-step
receipts and final status. A unit-test signature cannot prove a real click.

Production readiness also requires expiry/revocation, replay/concurrency,
changed scope/source/policy, interrupted execution and rollback evidence.
A missing real provider ID or SDK linkage remains a blocker; never invent it.
