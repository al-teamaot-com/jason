# Project Jason Session Record — 2026-09-21

## Subject

Endpoint Availability Verification and durable deferred-work behavior.

## Decision

A DRMM offline indication is evidence, not conclusive proof that an endpoint is powered off. Jason should use Last Seen to decide when secondary verification is warranted and should persist future rechecks so deferred work does not depend on technician memory.

Default behavior established:

- peer verification threshold: 2 hours offline;
- before threshold: persist a recheck for the threshold time;
- after threshold: attempt same-client/site read-only peer verification when an eligible online managed peer exists;
- intended peer checks: hostname resolution, ping by hostname, ping by last-known IP;
- peer success while DRMM is offline indicates a likely DRMM agent/service/path problem;
- failed ping is not conclusive proof of power-off;
- no suitable peer is a valid recoverable state and triggers another recheck;
- unknown Last Seen does not allow indefinite waiting.

## Persisted states

The evaluator supports explicit states including:

- `online`
- `recently_offline`
- `peer_verification_due`
- `peer_unavailable`
- `reachable_outside_drmm`
- `offline_likely`
- `inconclusive`

The persisted payload includes observation time, offline age, peer-verification requirement, recheck requirement, `next_recheck_at`, DRMM-agent suspicion, and normalized evidence.

## Governance

This work does not authorize disruptive action. Peer probing is designed as read-only/non-destructive and must remain within the same authorized client/site. Cross-client probing is prohibited.

Scheduling future work does not create authority. Any future scheduler must resume through the Central Orchestrator and revalidate principal, client, device, capability, policy, and terminal workflow state.

## Open production dependencies

1. Governed same-site peer discovery and network reachability probe capability.
2. Durable deferred-work scheduler with deduplication, restart recovery, bounded retries/aging, terminal-state cancellation, and audit.
